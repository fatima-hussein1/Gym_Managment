# 🏋️‍♂️ Gym Management System  
## منظومة إدارة نادي رياضي

مشروع تخرج مقدم كأحد متطلبات نيل درجة **البكالوريوس في علوم الحاسوب**  
جامعة الرفاق للعلوم التطبيقية والإنسانية – قسم علوم الحاسوب  
الفصل الدراسي: خريف 2025

---

## 📌 نبذة عن المشروع
منظومة **إدارة نادي رياضي** هي نظام برمجي متكامل يهدف إلى أتمتة وتنظيم جميع العمليات الإدارية والمالية داخل الأندية الرياضية، وذلك من خلال تحويل الإجراءات اليدوية والورقية إلى نظام إلكتروني دقيق وموثوق.

يساعد النظام على:
- إدارة الأعضاء والاشتراكات
- متابعة المدربين وأخصائيي التغذية
- إدارة الخزينة والحركات المالية
- توليد التقارير المالية والإحصائية
- تحسين كفاءة العمل ودعم اتخاذ القرار الإداري

---

## 🎯 أهداف النظام
- أتمتة عمليات تسجيل الأعضاء وتحديث بياناتهم
- إدارة الاشتراكات (نشطة – منتهية – مجمدة)
- متابعة المدربين والجلسات التدريبية
- إدارة الخطط الغذائية والاستشارات
- تسجيل الإيرادات والمصروفات اليومية
- توفير تقارير مالية وإدارية دقيقة
- تعزيز أمن البيانات عبر نظام صلاحيات متعدد المستويات

---

## ⚙️ خصائص ومزايا النظام
- واجهة استخدام سهلة ومرنة باستخدام **VB.NET**
- قاعدة بيانات مركزية باستخدام **SQL Server**
- نظام صلاحيات (مدير – موظف – مدرب – أخصائي تغذية)
- نظام تنبيهات لانتهاء الاشتراكات
- تقارير مالية وإحصائية باستخدام **Crystal Reports**
- تقليل الأخطاء البشرية ورفع كفاءة العمل الإداري
- قابلية التوسع والتطوير مستقبلًا

---

## 🧩 مكونات النظام
يشمل النظام الوحدات الرئيسية التالية:
- إدارة المستخدمين والصلاحيات
- إدارة الأعضاء
- إدارة المدربين
- إدارة أخصائيي التغذية
- إدارة باقات الاشتراك
- إدارة اشتراكات الأعضاء
- إدارة الخطط الغذائية والاستشارات
- إدارة الخزينة والحركات المالية
- إدارة الإيصالات والتقارير

---

## 🛠️ التقنيات المستخدمة
- **لغة البرمجة:** VB.NET  
- **قاعدة البيانات:** Microsoft SQL Server  
- **أداة التقارير:** Crystal Reports  
- **منهجية سلال الميته المعدل:** Modified Waterfall Model  
- **نماذج التصميم:** UML (Use Case, DFD, ERD, Sequence Diagrams)

---

## 🖥️ متطلبات التشغيل
- Windows OS  
- RAM: لا تقل عن 16 GB  
- SQL Server  
- .NET Framework  
- شبكة محلية (Local Network)

---

## 🚧 حدود النظام
- يعمل داخل بيئة محلية فقط (Local Server)
- لا يدعم الدفع الإلكتروني في النسخة الحالية
- لا يحتوي على تطبيق مخصص للأعضاء
- لا يدعم نظام الحضور بالبصمة أو RFID (قابل للإضافة مستقبلًا)
